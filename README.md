# Mentallico 🧠💼

**Mentallico** is a comprehensive, full-stack mental health platform designed to bridge the gap between users seeking support and professional therapists. The platform features a secure community space, a dynamic therapist directory, and robust authentication mechanisms.

---

## 🚀 Features

- **Therapist Directory:** A searchable and filterable directory for verified therapists with detailed profiles.
- **Community Forum:** A secure, interactive space for users to share thoughts, post anonymously, and support one another.
- **Robust Authentication:** Secure user and therapist onboarding with customized roles and permissions.
- **Interactive Admin Dashboard:** Seamless management of therapist seeding, user reports, and platform configurations.

---

## 🛠️ Tech Stack

### Backend
- **Framework:** Django & Django REST Framework (DRF)
- **Database:** PostgreSQL / SQLite
- **Architecture:** RESTful API Design

### Frontend
- **Library:** React.js
- **State Management & API Calls:** Axios & React Context API
- **Styling:** Tailwind CSS / Bootstrap
